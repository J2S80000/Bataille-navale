# 🎮 Guide de Gameplay - Bataille Navale

## Comment jouer

### 1️⃣ Écran principal
Cliquez sur l'une des 3 options:
- **Nouvelle partie vs IA** - Affrontez l'algorithme génétique
- **Partie 1v1 locale** - Jouez contre un ami sur le même téléphone
- **Partie en ligne** - Matchmaking avec d'autres joueurs (à venir)

### 2️⃣ Placement des navires
Avant de commencer, vous devez placer vos 5 navires:

**Navigation:**
1. Sélectionnez un navire dans la liste (droite)
2. Choisissez l'orientation: **Horizontal** ou **Vertical** (switch en haut)
3. **Cliquez** sur le plateau pour placer le navire
4. Répétez pour tous les 5 navires

**Les 5 navires:**
- ⚓ Porte-avions (5 cases)
- 🚢 Croiseur (4 cases)
- ⛵ Destroyer (3 cases)
- 🛥️ Sous-marin (3 cases)
- ⚡ Torpilleur (2 cases)

**Conseils:**
- Les navires ne peuvent pas se chevaucher
- Pas de placement en diagonal
- Cliquez sur "Prêt" (✓) pour confirmer quand tous les navires sont placés
- Vous pouvez voir les **recommandations stratégiques** en bas (défensive/équilibrée/agressive)

### 3️⃣ Gameplay
Une fois tous les navires placés:

**Mon plateau** (1ère page):
- Vos navires sont visibles
- Vous ne pouvez pas tirer ici

**Plateau adversaire** (2ème page):
- Grille vide (ou avec vos coups)
- **Cliquez** sur une case pour tirer
- Résultats: 🎯 Touché, ❌ Manqué, 💥 Coulé

**Tours alternés:**
- Les deux joueurs jouent tour par tour
- Les coups s'alternent automatiquement
- La partie se termine quand tous les navires d'un joueur sont coulés

### 4️⃣ Statistiques
Après chaque partie, consultez vos stats:
- Nombre total de parties
- Victoires et défaites
- Taux de victoire (%)
- Précision moyenne des tirs
- Zones privilégiées (où vous tirez le plus)

---

## Contrôles
- **Swiper horizontalement** entre "Mon plateau" et "Plateau adversaire"
- **Taper une cellule** pour placer un navire ou tirer
- **Basculer le switch** pour changer d'orientation des navires

## Problèmes courants

**Q: Je ne vois pas mes navires?**
- Vous êtes peut-être sur la page "Plateau adversaire". Swipez à gauche pour voir "Mon plateau".

**Q: Le placement est refusé?**
- Les navires ne peuvent pas se chevaucher
- Vérifiez que le navire sort du plateau
- Essayez une autre position

**Q: C'est mon tour mais je ne peux pas tirer?**
- Vous n'êtes peut-être pas sur la page "Plateau adversaire"
- Swipez à droite pour voir le plateau de l'adversaire

## 💡 Stratégie IA
L'IA utilise:
- **Algorithme génétique** - S'améliore en apprenant de vos parties
- **Heuristiques de prédiction** - Comprend vos patterns
- **Intervalles de confiance** - Évalue le risque de chaque coup

Pour un défi maximum, affrontez l'IA après plusieurs parties! 🚀
